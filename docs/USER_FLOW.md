# USER FLOW — 부가가치

## 1. 목적
사용자가 랜딩 → 자격 판정 → 취향 설문 → 추천 → 상세/저장에 이르는 경로와 분기·되돌아가기·예외 흐름을 정의한다.

## 2. 전체 플로우

```
[B1 랜딩] ──"로그인 없이 시작"──▶ [B2 1단계]
                                     │
        1-1 공통  A 주택소유(게이트) ─┤ 걸림 ▶ [즉시 종료 화면] (IMMEDIATE_REJECT)
                                     │           └ 사유·입력수정·공고안내·재진단
                  B 가구·나이 ───────┤
                  C 소득·자산 ───────┤ (B 완료 후에만 C 활성)
                  D 지역 ────────────┤
                                     ▼
                          [1-1 중간 결과] 통과후보/제외+사유/추가확인(NEEDS_MORE)/1-2 예고
                                     │ 후보 0개 ▶ [종료 화면] (ALL_REJECT)
                                     ▼
        1-2 세부  후보/NEEDS_MORE 유형 질문만 순차 ─▶ [1단계 완료 결과] (STAGE1_DONE)
                                     │ 통과 유형 0개 ▶ [종료 화면]
                                     ▼
[B3 2단계 진입 안내] 신청가능 유형·후보 주택 수·"자격 아닌 순서"·건너뛰기/수정
                                     ▼
      Q0 예산(필수·하드) ─ 0개 ▶ [예산 완화 제안] ─┐
                                     ▼             │
      Q1 지역(하드) ─── 0개 ▶ [지역 완화 제안] ────┤
                                     ▼             │
      Q2~Q6 취향(선택·가중치, 건너뛰기 가능) ◀──────┘
                                     ▼
              [추천 분석 중] (ANALYZING)
                                     ▼
   [B4 리스트+지도] (HAS_RESULTS / NO_RESULTS) ─▶ [B5 상세] ─▶ 저장/공유/공고링크
                                     ▼
              [B7 마이페이지] 재설문·수정·삭제      [B6 커뮤니티] (병렬 접근)
```

## 3. 1단계 상세 흐름 (스텝 A→B→C→D 고정 순서)

- **A 주택소유(게이트):** 본인 주택 소유=`있음` → 즉시 종료(전 유형 불가). 세대원 유주택·제한이력은 기록 후 계속(유형별 판정에서 사용). `[문서 원문]`
- **B 가구·나이:** 생년월일 → 만 나이 자동. 가구원 추가(본인·배우자·부모·자녀, 태아 포함) → 가구원 수 자동.
- **C 소득·자산:** 가구원 수 확정 후 **해당 가구원 수 줄의 월소득 5구간**을 노출. 총자산 8구간, 자동차 3단.
- **D 지역:** 부산 거주 여부(재개발·매입 판정용).
- **되돌아가기:** 상위 스텝 수정 시 하위 판정 무효화·재계산.

## 4. 1-2 유형별 분기 (후보 유형만)

- **통합:** 계층(청년/신혼·한부모/고령자/일반) → 신혼이면 혼인개월(≤84) + 맞벌이 → 판정.
- **행복:** 계층(대학생/청년/사회초년생/신혼·한부모/고령자/주거급여) → 대학생·사회초년생은 상태(재학/졸업2년내/소득활동5년내), 신혼은 혼인개월+맞벌이 → 판정.
- **재개발:** 2023.3.28 이후 출산(입양·태아) 자녀 수(0/1/2+) → 판정. (2025 기준 배지)
- **매입 일반:** 1순위 여부(수급·한부모·차상위·65세·장애인) → 출산 자녀 수(0/1/2+) → 1순위 소득무관, 아니면 2순위 도시 50% → 판정.
- **매입 청년:** 1순위 여부 → 예=자격확인 종료 / 아니오 → 2순위(부모합산)면 부모 월소득·총자산 입력, 3순위(본인만) → 판정.

## 5. 2단계 흐름 규칙
- Q0·Q1은 하드필터(순서 고정, 필수/지역). 이후 Q2~Q6은 건너뛰기 가능.
- 건너뛴 축은 최종 가중치에서 재정규화 대상 `[정책 결정 필요]`.
- Q4는 "필요 여부" 게이트 → "아니요"면 축 제외.

## 6. 사용자 시나리오 (경로 예시)
- **정상:** 랜딩→1-1→(후보 3개)→1-2→(통과 2개)→진입안내→Q0~Q6→분석→결과 12개→상세→저장.
- **즉시 종료:** 1-1 A에서 본인 주택 `있음` → 종료 화면 → "입력 수정"으로 A 복귀.
- **필터 0개:** Q0 예산 과소 → 완화 제안(예산 +α 슬라이더/2·3순위 조건 설명) → 재적용.
- **복구:** 이탈 후 재방문 → persist 상태 감지 → "이어서 하기 / 처음부터" 선택(RESTORED).

## 7. 예외 흐름
- 유효성 실패(생년월일 미래·미선택) → 인라인 에러, 다음 버튼 비활성.
- 2단계 직접 진입 시도(1단계 미완료) → 1단계로 리다이렉트.
- mock API 오류 → 재시도 UI.

## 8. 접근성 / 개인정보 / 백엔드 / 완료조건
- 접근성: 키보드만으로 전 분기 완주, 스텝 이동 시 포커스 이동·스크린리더 안내.
- 개인정보: 흐름 중 입력은 로컬 저장, 종료/삭제 시 파기. 완화 제안·재진단에서 재사용만.
- 백엔드: 판정·추천 호출 지점이 `services`로 고정되어 흐름 변경 없이 교체 가능.
- 완료조건: 위 모든 경로(정상·게이트·0개·복구·예외)가 mock으로 재현되고 되돌아가기 재계산이 정확.
