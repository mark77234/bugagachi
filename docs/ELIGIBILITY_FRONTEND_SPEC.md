# ELIGIBILITY FRONTEND SPEC — 1단계 자격 판정

> **Source of Truth:** 첨부 `ELIGIBILITY.md` + `stage1_filter.py`(실행·검증 완료). 본 문서의 모든 수치는 원문 그대로이며 임의 변경·단순화하지 않는다.
> **기준연도:** 소득·자산 2026년. **재개발임대만 2025년 공고 기준**(2026 미발표) → UI 배지 필수.
> 표기: `[문서 원문]` / `[정책 결정 필요]` / `[문서 내 불일치 — 확인 필요]`.

## 1. 목적
5개 유형(TONGHAP·HAENGBOK·JAEGAEBAL·MAEIP_ILBAN·MAEIP_CHUNG)에 대해 1-1 공통 입력으로 후보를 좁히고, 1-2 유형별 세부로 통과/탈락을 확정하는 프론트엔드 판정 명세. 규칙은 `config`에, 판정은 `services/eligibility` 순수함수에 둔다.

## 2. 사용자 시나리오
- 검증 케이스(회귀 테스트 고정): **27세 청년·부모 유주택·자산 2억 → 1-1 후보 {통합, 행복, 매입청년}, 1-2 매입청년 3순위 통과.** `[문서 원문]`

## 6. 판정 로직 (프론트 포팅 대상, `stage1_filter.py` 동치)

```ts
const 만 = 10_000;
function 소득상한(잣대: 'MEDIAN'|'URBAN', n: number, 배율: number): number {
  const base = INCOME_BASE_100[잣대][clamp(n,1,8)];
  const 가산 = n===1 ? 0.2 : n===2 ? 0.1 : 0;
  return Math.round(base * (배율 + 가산));
}

// 1-1 공통
function stage1_1(inp): { 후보: TypeCode[]; 게이트: string|null; 상세 } {
  if (inp.본인주택소유) return { 후보: [], 게이트: '본인 주택 소유 → 전 유형 불가', 상세: {} };
  const 세대전원무주택 = !inp.세대원유주택자;
  const n = clamp(inp.가구원수, 1, 8);
  // 각 유형: 총자산 초과 / 자동차 초과 / (배율≠null) 소득 초과 /
  //          (!세대전원무주택 && !무주택자계층) 세대원 유주택 / (부산거주 요구) / (연령)
  // 사유 없으면 후보. 매입(배율 null)은 소득 판정을 1-2로 이월.
}

// 1-2 세부: 계층/순위별 배율·자산·자동차 적용. 재개발·매입일반은 출산완화 인덱스[min(출산,2)].
//           매입청년 2순위는 (본인+부모) 소득·자산 합산. 대학생 자동차=0이면 '소유 불가'.
```

**범위→대표값 변환:** UI 구간 → 상한값(마지막 ∞). 자동차 미보유=0 / 이하=45,420,000 / 초과=1e12.

## 7. 화면 상태
`IN_PROGRESS`(스텝 A~D) · `VALIDATION_ERROR`(미선택·미래 생년월일) · `IMMEDIATE_REJECT`(게이트) · 1-1 결과(`PARTIAL_PASS`/`ALL_REJECT`) · 1-2 진행 · `STAGE1_DONE`. 각 유형 결과는 `PASS`/`FAIL`/`NEEDS_MORE`.

## 8. 데이터 입출력
- 입력: `EligibilityCommonInput` + `EligibilityDetailInput`.
- 출력: `EligibilityTypeResult[]`(status·사유·확인할조건·baseYear). 사유는 코드가 붙인 텍스트 배열(예: "총자산 초과", "2순위 부모포함 자산 초과").

## 9. 예외 상황
- 게이트: 본인 주택소유 → 즉시 종료.
- 후보 0개 → 종료 화면.
- 소득 미선택 상태에서 다음 → 차단.
- 매입청년 2순위인데 부모 소득·자산 미입력 → 차단.
- `[불일치 C1/C2/C3]` 발생 지점은 config 주석 + 화면 툴팁으로 "검토 중 기준" 표기.

## 10. 접근성
- 세그먼트 선택은 `role=radiogroup`, 각 보기 `aria-label`. 게이트 결과는 텍스트+아이콘.
- "왜 묻는가" 도움말을 `aria-describedby`로 문항에 연결.

## 11. 개인정보 주의사항
- 생년월일·소득·자산은 판정에만 사용, 서버 미전송(이미지 카피 "입력 정보는 자격 판정에만 사용돼요" 준수). 로컬 저장, 삭제 제공.

## 12. 추후 백엔드 연동 포인트
