# busan_rental_scores.csv — 순위 산출 가이드

부산 공공임대주택 추천 서비스의 사전계산 점수 파일 사용법. Q0~Q6 응답을 받아 주택 순위를 만드는 절차를 설명한다.

## 파일 개요

`busan_rental_scores.csv` — 659행 × 84열, UTF-8-SIG.

**1행 = 임대주택 1호실**이다. 659행은 41개 위치(건물)에 분포한다. 한 건물의 여러 호실은 위치 기반 점수(`*_score`)가 전부 동일하고, 면적·방수·보증금만 다르다. 순위는 행 단위로 매기되, 결과화면에서 같은 건물이 여러 개 뜨는 것이 부담되면 건물 단위로 접어서 보여준다.

모든 `*_score` 열은 **0~1이고 높을수록 좋다**. 모든 `*_dist_m` 열은 보정거리(직선거리 × 1.291, 부산 실측 우회계수)이며 단위는 미터다.

전처리는 끝나 있다. 런타임에서 할 일은 **필터링 → 축별 점수 집계 → 가중합**뿐이며, 거리 계산이나 백분위 계산을 다시 하지 않는다. 예외는 Q2 앵커와 Q6 t 두 가지로, 사용자 입력에 의존하므로 런타임에서 계산한다.

---

## 전체 절차

```
Q0 예산 필터  →  Q1 지역 필터  →  남은 후보에 대해
Q2~Q6 축별 점수 계산  →  응답 없는 축 제외 후 가중치 재정규화  →  가중합  →  정렬
```

## Q0. 예산 — 필터

**입력**: 보증금 상한, 월세 상한 (둘 다 선택 사항)

**사용 열**: `deposit_krw`, `rent_krw`

```python
if max_deposit is not None:
    df = df[df['deposit_krw'] <= max_deposit]
if max_rent is not None:
    df = df[df['rent_krw'] <= max_rent]
```

점수화하지 않는다. 예산을 넘는 주택이 상위에 노출되면 추천이 모순되기 때문이다.

**주의**: `deposit_krw`와 `rent_krw`가 결측인 행이 49개 있다(원자료에 임대조건 없음). 비교 연산에서 `NaN`은 자동으로 `False`가 되어 제외되는데, 이것이 의도한 동작인지 정해야 한다. 남기려면 `df['deposit_krw'].isna() | (df['deposit_krw'] <= max_deposit)`로 처리하고 결과화면에 "임대조건 미공개"로 표시한다.

`priority_rank`(순위 1·2) 열이 있지만 **금액은 이미 순위 구분 없이 평균 처리**되어 있다. 필터링에 이 열을 쓰지 않는다.

## Q2. 직장·학교 앵커 — 가중치 0.30

**입력**: 주소 → 지오코딩하여 위경도 확보 (미입력 가능)

**사용 열**: `lat`, `lon` (주택 좌표) → `anchor_dist_m`, `anchor_score`에 결과를 채운다

`anchor_lat` / `anchor_lon` / `anchor_dist_m` / `anchor_score` 4개 열은 **비어 있는 입력·파생 슬롯**이다. 다음을 실행해 채운다.

```python
from pyproj import Transformer
import numpy as np
TF = Transformer.from_crs("EPSG:4326", "EPSG:5186", always_xy=True)

ax, ay = TF.transform(anchor_lon, anchor_lat)
hx, hy = TF.transform(df['lon'].values, df['lat'].values)
df['anchor_dist_m'] = np.hypot(hx - ax, hy - ay) * 1.291
df['anchor_score']  = np.interp(df['anchor_dist_m'],
                                [0, 5000, 10000, 30000],
                                [1.0, 1.0, 0.7, 0.0])
```

위경도로 직접 유클리드 거리를 계산하면 안 된다. 반드시 EPSG:5186으로 투영한 뒤 계산한다.

매듭 근거는 통계청 「2024년 통근 근로자 이동특성 분석」의 4구간 분류다. 직주근접(≤5km) / 단거리(5~10) / 중거리(10~30) / 장거리(>30)의 경계값 3개를 그대로 매듭으로 썼다. 30km를 넘으면 0점으로 평탄하다.

**미입력이면 이 축을 제외**한다(아래 재정규화 참조).

| 선택지 | 열 이름 | 스케일 |
|---|---|---|
| 병원 | `hospital_score` | 차량 5/10/15/20km |
| 도서관 | `library_score` | 차량 5/10/15/20km |

S_infra = df[[f'{k}_score' for k in selected_infra]].mean(axis=1)

대응하는 `*_dist_m` 열은 결과화면 설명용이다("병원까지 1.2km" 등).

## Q5. 취향 가게 — 가중치 0.15

**입력**: 칩 10종 중 최대 5개 선택

**사용 열**: 선택 칩의 `*_score` (반경 750m 업종 수의 백분위, 건물 단위)

| 칩 | 열 |
|---|---|
| 카페 | `cafe_score` |
| 편의점 | `convenience_score` |
| 헬스장 | `gym_score` |
| 빨래방 | `laundry_score` |
| 동물병원 | `vet_score` ⚠️ |
| 스터디카페 | `study_cafe_score` |
| 밥집 | `restaurant_score` |
| 베이커리 | `bakery_score` |
| 미용실 | `hair_salon_score` |
| 약국 | `pharmacy_score` ⚠️ |

```python
cols = [f'{k}_score' for k in selected_chips]
cols = [c for c in cols if df[c].notna().any()]     # 전량 결측 칩은 제외
S_shop = df[cols].mean(axis=1) if cols else None
```

`*_cnt_750m` 열은 실제 개수이며 결과화면 설명용이다("반경 750m에 카페 37곳").

**⚠️ `vet_score`는 전량 결측이다.** 동물병원은 수의사법 등록시설이라 소상공인 상가데이터에 수록되지 않는다. 사용자가 동물병원 칩을 골랐다면 0점을 주지 말고 **항목에서 제외**한 뒤 유사 카테고리를 재제안한다. 0점을 주면 모든 주택이 동일하게 감점되어 순위에 기여하지 못하면서 총점만 떨어뜨린다.

**⚠️ `pharmacy_score`는 값이 있으나 신뢰도가 낮다.** 상가데이터에 약국이 극소수만 수록되어 고유 백분위가 2개뿐이다. 사실상 변별력이 없다.

## Q6. 동네 분위기 — 가중치 0.10

**입력**: 슬라이더 위치 `t` (0=조용 ~ 1=번화), 또는 "상관없어요"

**사용 열**: `bustle_pct`(수식의 c), `noise_pct`(수식의 n) → `vibe_t`, `vibe_score`에 결과를 채운다

```python
c = df['bustle_pct'].values      # 반경 750m 상가 총량의 백분위
n = df['noise_pct'].values       # 소음업종 구성비의 백분위
df['vibe_t'] = t
df['vibe_score'] = (1 - np.abs(c - t) / max(t, 1 - t)) * (1 - 0.5 * n * (1 - t))
S_vibe = df['vibe_score']
```

앞부분은 사용자 목표 `t`에 꼭짓점을 둔 삼각형으로, 동네 번화도 `c`가 `t`에 얼마나 가까운지를 잰다. `max(t, 1-t)` 나눗셈은 어떤 `t`에서도 최악값이 0이 되게 하는 정규화다.

뒷부분은 소음 감점이다. `(1-t)` 결합으로 번화를 선호할수록 감점이 약해지고, `t=1`이면 완전히 사라진다. 계수 0.5는 감점 상한 캡이다.

**`t=0.5`가 가장 가혹한 설정**이라는 점에 유의한다. 이때만 양쪽 극단(c=0, c=1)이 동시에 0점을 받는다. 슬라이더 초기값을 정중앙에 두면 후보가 급감할 수 있다.

"상관없어요"면 축을 제외한다.

## 축 제외와 가중치 재정규화

어떤 축이든 응답이 없거나 계산 불가면 제외하고, **남은 축의 가중치 합이 1이 되도록 재정규화**한다. 어떤 응답 조합에서도 만점이 1.0이어야 한다.

```python
W = {'anchor': 0.30, 'infra': 0.25, 'care': 0.20, 'shop': 0.15, 'vibe': 0.10}
axes = {k: v for k, v in {
    'anchor': S_anchor, 'infra': S_infra, 'care': S_care,
    'shop': S_shop, 'vibe': S_vibe
}.items() if v is not None}

tot = sum(W[k] for k in axes)
total_score = sum(axes[k] * W[k] / tot for k in axes)
df = df.assign(total_score=total_score).sort_values('total_score', ascending=False)
```

축이 제외되는 경우는 다음과 같다.

- Q2: 앵커 주소 미입력
- Q3·Q4: 해당 문항에서 아무 항목도 선택하지 않음
- Q5: 선택한 칩이 전부 계산 불가(예: 동물병원만 선택)
- Q6: "상관없어요" 선택
- Q5·Q6 공통: `commerce_data`가 `미보유`인 주택 — 상가데이터가 없는 지역이다

## commerce_data 처리

`commerce_data` 열은 해당 주택에 상가데이터가 있는지를 나타낸다. 현재 수영구 310행은 `보유`, 기장군 349행은 `미보유(Q5·Q6 계산불가)`다.

`미보유` 행은 Q5·Q6 관련 열이 전부 결측이므로, **주택마다 활성 축이 달라진다.** 사용자가 Q5·Q6에 응답했더라도 기장군 주택은 그 두 축을 빼고 재정규화해야 한다.

```python
has_commerce = df['commerce_data'].eq('보유')
```

이 상태에서 서로 다른 주택을 총점으로 직접 비교하면 축 구성이 달라 불공정할 수 있다. 결과화면에 "이 지역은 상권 데이터 미수집으로 취향·분위기 점수가 제외되었습니다"를 명시하고, 가능하면 상권데이터 보유 지역과 미보유 지역을 나눠서 보여주는 편이 안전하다.

## 결과화면에 함께 표시할 것

총점만 보여주면 왜 그 집이 추천됐는지 알 수 없다. 다음을 함께 낸다.

- **축별 내역**: `anchor_dist_m`으로 "직장에서 4.2km — 직주근접", `cafe_score`로 "카페 밀도 상위 9%", `vibe_score`로 "선호 분위기와 86% 일치"
- **최약점 축**: 축별 점수 중 최소값을 상시 병기해 기대 관리
- **변별력 낮은 축 안내**: 후보군 내에서 특정 축의 점수 분산이 거의 0이면 "이 지역은 병원 접근성이 모두 우수해 순위는 취향·분위기에서 갈립니다"를 표시. 실제로 수영구 내에서는 `hospital_score`와 `library_score`가 전 주택 1.000이다.

## 자주 하는 실수

**거리를 다시 계산하지 않는다.** `*_dist_m`은 이미 EPSG:5186 투영 + 우회계수 1.291이 적용된 값이다. 위경도로 다시 계산하면 값이 어긋난다.

**백분위를 후보군 기준으로 다시 계산하지 않는다.** `*_score` 중 Q5·Q6 계열은 전 재고 임대주택을 모집단으로 계산된 주택 고유 속성이다. 필터링된 후보군 안에서 다시 순위를 매기면 소표본이 증폭되고 같은 주택의 점수가 검색 조건에 따라 달라진다.

**결측을 0으로 채우지 않는다.** 결측은 "점수가 낮다"가 아니라 "계산할 수 없다"이며, 항목 제외로 처리해야 한다.

**`total_score`를 절대 평가로 읽지 않는다.** 축 구성이 응답마다 달라지므로 서로 다른 사용자의 총점을 비교하는 것은 의미가 없다. 같은 응답 내에서의 상대 순위로만 쓴다.
