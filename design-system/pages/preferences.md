# Page Rules — B3 2단계 취향 설문

단계: 예산 → 지역 → 자주 가는 장소 → 기반시설 → 돌봄·교육 → 취향 가게 → 동네 분위기 → 완료.
진입 안내: 신청 가능 유형·후보 주택 수·"자격 아닌 추천 순서"·건너뛰기/수정 안내.

## 문항별
- **Q0 예산(하드필터)**: 보증금+월세 한 화면. 숫자 입력 + 빠른 선택 버튼, 만원 단위, 천단위 구분자 자동, 현재값 요약. "예산 밖 주택은 목록에서 제외돼요"를 부담 없이 안내.
- **Q1 지역(하드필터)**: 부산 구·군 Chip/체크카드 복수 선택. "상관없어요" 선택 시 나머지 해제. 지도 장식 최소.
- **Q2 자주 가는 장소(0.30)**: 장소 유형 + 이름 + 도로명주소 mock 자동완성, 복수 추가, 선택 요약 카드.
- **Q3 기반시설(0.25)**: 아이콘+이름 선택 칩. "선택한 시설만 점수 반영" 안내. "종합병원은 차량 기준" 설명.
- **Q4 돌봄·교육(0.20)**: 필요 여부 먼저 → 아니요면 세부 건너뜀(축 제외) / 예면 시설 칩. 자녀 개인정보 과다 수집 금지.
- **Q5 취향 가게(0.15)**: 기본 칩 10종 + 직접 입력 + 선택 요약. "가까운 한 곳이 아니라 선택지의 풍부함(밀도)을 평가" 설명.
- **Q6 동네 분위기(0.10)**: 큰 카드 3개 — 조용한(상업밀도 낮고 주거 중심) / 적당한(편의·주거 균형) / 번화한(상업·유동인구 많음). 추상어만 쓰지 말고 설명 병기.

## Motion
단계 전환, 진행률 변경, Q4 조건부 등장, 예산 요약 업데이트. 결과 이동은 analyzing 화면 경유.

## 접근성
각 문항 `fieldset/legend` + 가중치 배지 + "왜 묻는가". 건너뛰기 버튼 포커스 가능. 하단 고정 이전/다음(모바일).
