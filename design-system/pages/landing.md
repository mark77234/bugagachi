# Page Rules — B1 Landing

신뢰성 있는 공공서비스 소개 페이지(마케팅 사이트 아님).

## 레이아웃
- 상단 `AppHeader`. 콘텐츠 max 1024px, 섹션 간 48px.
- 배경 `--color-bg`, 히어로만 살짝 primary-subtle 톤 가능(그라데이션 금지).

## 섹션
1. **Hero**: h1 "부산에서 나에게 맞는 공공임대주택 찾기" + 보조 "자격 확인부터 생활 취향 추천까지". CTA 2개: `추천 시작하기`(primary lg) → `/eligibility`, `모집공고 둘러보기`(outline) → `/recommendations`.
2. **이용 과정**: 4스텝 카드(자격 확인 → 생활 조건 입력 → 추천 결과 → 공식 공고 확인). Lucide 아이콘.
3. **지원 임대 유형**: 5카드(통합공공임대/행복주택/재개발임대/매입임대 일반/매입임대 청년). 재개발 카드에 "2025년 기준" 배지.
4. **추천 기준**: 6항목(예산·출퇴근/통학·생활 인프라·돌봄/교육·취향 시설·동네 분위기) + 가중치 힌트.
5. **신뢰 안내**(`InformationBanner`+`PrivacyNotice`): 추천 vs 법적 자격 확정 차이, 사용 데이터 안내, 공식 공고 확인 필요.

## Motion
히어로 등장 fade/up 1회, 카드 stagger 40–60ms. 반복 없음.

## 접근성
히어로 h1 단일, 각 섹션 `SectionHeader`(h2). CTA 44px+.
