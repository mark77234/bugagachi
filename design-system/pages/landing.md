# Page Rules — B1 Landing / Service Hub

부산 공공임대의 추천·AI 안내·전체 지도 중 다음 행동을 고르는 공공서비스 허브다.

## 레이아웃

- 상단 `AppHeader`, 콘텐츠 최대 1280px.
- Hero와 서비스 카드를 같은 컨테이너 축에 정렬한다.
- 그라디언트·glass·neon·3D 효과를 사용하지 않는다.
- 데스크톱은 12-column Bento: 추천 7열/2행, AI·지도 5열/각 1행.
- 태블릿은 추천 전체 폭 + AI/지도 2열, 모바일은 추천→AI→지도 1열이다.

## Hero

- Eyebrow: `부산 공공임대 · 자격 확인부터 추천까지`
- h1: `부산에서 나에게 맞는 공공임대주택을 찾아보세요`
- Primary CTA: `내 조건으로 추천받기` → 기존 `/eligibility`
- 정량 근거가 없는 소요시간과 최신 공고처럼 읽히는 배지는 표시하지 않는다.
- `로그인 없이 시작`, `입력 정보는 이 브라우저에만 저장`만 보조 정보로 제공한다.

## 서비스 진입 카드

1. **맞춤 추천**: primary teal, 가장 큰 카드, `/eligibility`
2. **AI 안내**: warning-subtle, `데모` 배지, `/chat`
3. **전체 지도**: primary-subtle, 데모 주택 12곳 명시, `/map`

카드는 전체가 하나의 `Link`다. 내부 원형 화살표는 `aria-hidden` 시각 요소이며 별도 버튼이 아니다. 제목·설명은 `aria-labelledby`와 `aria-describedby`로 연결한다. 일러스트는 동일한 선·면 스타일의 장식용 inline SVG이고 스크린리더에서 제외한다.

## 하단 정보

- 맞춤 추천 이용 과정 4단계
- 지원 임대 유형 5개
- 추천은 법적 자격 확정이 아니라는 고지
- 주택·모집 정보가 데모 데이터 12곳이라는 고지
- 입력 정보가 서버로 전송되지 않는다는 개인정보 안내

기존 차별점·추천 기준의 반복 카드 섹션은 서비스 카드와 이용 과정으로 통합한다.

## Motion

- Hero fade/up 220–240ms.
- 서비스 카드 순차 등장 40ms 간격.
- 카드 hover y 최대 -2px, pressed y 1px.
- 화살표 x 이동 4px.
- `useReducedMotion` 사용 시 위치 이동과 stagger를 제거한다.
- 라우트 종료 애니메이션은 사용하지 않는다.

## 접근성

- 한 페이지에 h1은 하나.
- 모든 CTA와 터치 영역은 44px 이상.
- 서비스 카드 내부에 button/anchor를 중첩하지 않는다.
- 키보드 포커스는 3px ring으로 표시한다.
- 색상만으로 세 기능을 구분하지 않는다.
- 360px와 200% 확대에서 텍스트·일러스트 겹침과 가로 스크롤이 없어야 한다.
- 장식용 SVG는 `aria-hidden="true"`와 `focusable="false"`를 사용한다.
- route 이동 후 `main`으로 포커스를 옮긴다.

## 신뢰·데이터 표현

- `/chat`은 실시간 AI가 아닌 키워드 기반 로컬 데모로 명시한다.
- `/map`과 목록의 12건은 시연용 데이터이며 실시간 공고처럼 표현하지 않는다.
- 최종 자격·공고 내용은 MyHome 등 공식 기관에서 확인하도록 안내한다.
