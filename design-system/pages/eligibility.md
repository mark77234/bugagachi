# Page Rules — B2 1단계 자격 (핵심 화면, 이미지 최다 참고)

## 레이아웃
- 상단 로고+서비스명(부가가치) + 진행 상황("1단계 자격 확인").
- 가로 스텝퍼: `A 주택 소유 · B 가구·나이 · C 소득·자산 · D 지역` (+ 이후 유형별). 현재=강조, 완료=체크, 이후=연한색.
- 데스크톱 2단: 좌측 `QuestionCard`(720–880px 영역) + 우측 `SummarySidebar`(스티키). 모바일 1단 + 요약 접이식 + 하단 고정 이전/다음.
- 카드 하단: 이전/다음, 저장 상태("자동 저장됨"), 예상 남은 시간.

## 스텝별
- **A 주택 소유(게이트)**: 2열 `ChoiceCard`(없음/있음) × 3문항. `role=radio`. 본인 주택 "있음" 등 위험 답변 → 다음 화면에서 결과를 갑자기 숨기지 말고 `ConfirmationDialog`로 "이 경우 신청이 어려워요, 계속할까요?" 확인 안내.
- **B 가구·나이**: 생년월일 DatePicker → 만 나이 자동 표시. 가구원 추가 카드(관계 선택·삭제), 태아 포함 도움말(Tooltip/Accordion).
- **C 소득·자산**: 직접 금액 강요 금지 → 문서의 범위 선택지(`RangeSegment`). 가구원 수에 따라 월소득 5구간 동적 변경. 총자산 8구간, 자동차 3단. "왜 필요한가" Tooltip/Accordion.
- **D 지역**: 부산 거주 라디오 + "부산 거주가 적용되는 유형(재개발·매입)" 설명. 위치 자동수집 안 함 명시.

## 1-1 결과
- 통과 후보 유형 카드 + 상태 배지(통과/추가 확인 필요/제외, 색+아이콘). 제외 사유 Accordion. "1-2 계속하기" CTA.

## 1-2
- 긴 단일 폼 금지 → 유형별 섹션/순차 스텝. 현재 어느 유형 확인 중인지 상단 표시. 후보 아닌 유형은 완전히 숨김.

## 최종 결과
- 신청 가능성 유형 / 추가 확인 필요 / 어려운 유형 + 유형별 이유. 입력 수정, "2단계 취향 추천으로", "공식 자격 확정 아님" 안내.

## Motion
스텝 전환 fade+X(12–24px, mode="wait"), 조건부 질문(맞벌이·부모입력) 등장, 결과 카드 stagger 40–70ms.

## 접근성
`fieldset/legend`로 문항 그룹화, 단계 변경 시 제목 포커스, 오류 `aria-live`. 재개발 "2025년 기준" 배지.
