# Page Rules — B4 추천 리스트 + 지도

## 레이아웃
- 데스크톱: 좌 리스트/필터 + 우 지도(화면 50–60%). 카드↔마커 동기화(선택 강조).
- 모바일: 리스트/지도 토글, 필터는 Bottom Sheet, 선택 마커 카드 하단 표시.
- 상단: 선택한 추천 조건 요약 바 + 정렬(추천/월세/보증금/거리) + 필터(유형·모집중·구·군).

## 지도 (Key 없음 → mock)
- `MapProvider` 인터페이스 + `MockMapProvider`(마커 위치 mock·선택 상태). 실제 지도 요청 금지. 향후 `KakaoMapProvider` 교체.

## 추천 카드
임대주택명·유형·위치·모집상태·신청기간·보증금·월세·전용면적 + 추천 상태 + **추천 이유 2~3개(정성)** + 확인 필요 조건 + 관심 저장 + 상세 보기.
점수 숫자만 강조 금지 — 근거 문구 우선.

## 상태
`ANALYZING`(로딩)·`HAS_RESULTS`·`NO_RESULTS`(빈 상태)·`FILTER_EMPTY`(완화 제안)·`MAP_LOADING`·`API_ERROR_MOCK`(재시도).

## Motion
결과 카드 최초 등장 stagger 40–70ms, 지도↔리스트 선택 동기화 하이라이트, 시트 열기. 반복 없음.
