# Page Rules — B6 커뮤니티

공공서비스 UI와 일관된 카드형 피드. 과도한 SNS 디자인 금지.

## 구성
- 게시판 구분: 질문(Q&A) · 후기(입주 후기) · 정보공유(공고 정보).
- 필터: 지역(구·군) · 임대 유형. 정렬: 인기 / 최신. 검색.
- 카드: 카테고리 배지 + 제목 + 요약 + 지역/유형 태그 + 좋아요/댓글 수 + 작성 시각.
- 글쓰기: mock 화면(작성 폼, 실제 저장은 mock).
- 운영 정책·신고 기능 노출(카드 메뉴 / 하단 안내).

## Motion
피드 카드 등장 최소 stagger. 반복/과한 효과 금지.

## 접근성
카드 전체가 링크가 아닌 제목 링크 + 보조 액션 분리. 신고는 명확한 라벨.
