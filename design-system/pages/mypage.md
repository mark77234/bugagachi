# Page Rules — B7 마이페이지

Bento Grid 대시보드 허용하되 카드 크기·정보 밀도를 과도하게 다양화하지 않음.

## 구성 (카드)
- 내 자격 결과(유형별 상태 요약 + 재개발 2025 배지)
- 추천 설정(예산·지역·선택 축 요약)
- 저장 주택 / 최근 본 주택
- 관심 모집공고
- 알림 설정 UI(토글)
- 정보 수정 / 설문 다시 하기(1단계·2단계 진입)
- 데이터 삭제(ConfirmationDialog) / 로그아웃 mock

## 상태
비로그인(GUEST) 안내 배너 + 로컬 저장 데이터 기반 표시. 데이터 없으면 EmptyState.

## Motion
카드 등장 최소. 저장/삭제 피드백. 반복 없음.

## 접근성
토글은 라벨+상태 텍스트, 삭제는 확인 다이얼로그 + 되돌릴 수 없음 안내.
