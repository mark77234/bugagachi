# Page Rules — B5 상세

이미지 중심 부동산 서비스 아님 → 공고·추천 근거 중심.

## 구성
1. 기본 정보(주택명·유형·주소·모집상태)
2. 임대 조건(순위별 보증금·월세·전용면적)
3. 위치 + 지도(mock)
4. 모집 일정(신청 기간·공급 세대수)
5. 신청 자격 요약(내 판정 결과 병렬 표시 — 취향 점수와 혼합 금지)
6. **내 조건과 일치하는 이유** + 항목별 점수 분해
7. 주변시설
8. 공식 공고 확인 링크
9. 리뷰(태그: 교통·소음·편의시설·관리상태)
10. 저장/공유

## 추천 점수 표시 (설명형)
총 추천 상태 + 축별(자주 가는 장소·기반시설·돌봄교육·취향가게·동네분위기) 막대 + **원본 값**(실제/보정 거리·시설 개수·백분위·계산 기준). 점수만 노출 금지.

## Motion
섹션 등장 최소, 저장 완료 피드백. 3D/패럴랙스 금지.

## 접근성
점수 막대는 수치+텍스트 병기, 색 단독 금지. 공고 링크 외부 표시.
